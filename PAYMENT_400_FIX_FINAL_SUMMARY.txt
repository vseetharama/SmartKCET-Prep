ISSUE: Trial/Monthly/Yearly plans fail with HTTP 400 Bad Request
STATUS: ✅ FIXED AND VERIFIED
DEPLOYMENT: Ready

================================================================================
ROOT CAUSE
================================================================================

SQLAlchemy UUID column type mismatch with SQLite:
- SQLite stores UUIDs as strings
- ORM expected UUID objects for comparison
- Plan lookup queries silently failed
- ValueError raised → HTTP 400 response

================================================================================
FIXES APPLIED
================================================================================

1. SUBSCRIPTION_MODELS.PY (Line 101)
   ✅ Uuid → Uuid(as_uuid=False, native_uuid=False)
   
   Tells SQLAlchemy:
   - Return strings from database (not UUID objects)
   - SQLite doesn't have native UUID type (use string)

2. SERVICE.PY (Line 74)
   ✅ Added import: from sqlalchemy import cast, String
   
   Required for cast() function in queries

3. SERVICE.PY (Line 80 - create_institution_order)
   ✅ Changed: SubscriptionPlan.id == plan_id
   ✅ To: cast(SubscriptionPlan.id, String) == str(plan_id)
   
   Forces string comparison for proper UUID matching

4. SERVICE.PY (Line 388 - create_student_order)
   ✅ Changed: SubscriptionPlan.id == plan_id
   ✅ To: cast(SubscriptionPlan.id, String) == str(plan_id)
   
   Forces string comparison for proper UUID matching
